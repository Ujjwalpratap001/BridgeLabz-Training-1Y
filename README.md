# BridgeLabz Training – Year 1

A Java programming and problem-solving practice repository maintained by **Ujjwal Pratap** during his first-year BridgeLabz training journey. It organizes introductory programming exercises, assignments, and practice work around Java fundamentals.

## What’s inside

- **Basic programs:** introductory coding exercises and assignments.
- **Java control flow:** practice with program flow and decision-making constructs.
- **Assignments:** structured exercises grouped under the training folders.
- **Practice work:** problem-solving tasks used to strengthen programming fundamentals.

## Repository structure

```text
BridgeLabz-Training-1Y/
└── BridgeLabz-Training-1Y/
    ├── Java-Control-Flow
    └── basic-programs/
        ├── 01-Practice-Problems/
        ├── Assignment
        ├── Assignment02/
        ├── Java-Control-Flow/
        └── NewAssignment/
```

The repository currently uses the `programming-constructs` branch for this training work.

## Run a Java program

Install a JDK, open the folder containing a `.java` file, and compile/run it:

```bash
javac FileName.java
java ClassName
```

Replace `FileName` and `ClassName` with the actual source filename and public class name.

## Purpose

This repository documents a practical learning path in Java, programming constructs, and foundational problem solving. It is a training archive rather than a packaged application.
